## 普通主动效果按同一 ID 执行

原表普通技能槽和 `Rare.skill` 是不同引用。普通主动报出其技能 ID 时，目录必须以相同 ID 匹配效果；不能从另一个形态或按 `Ultimate` 分类借一条。缺同号实现时可走原 R1 已有职业/角色兼容，不能因此称已复原原技能伤害、目标或触发条件。

## 原表动作类型

`FightActionBeforeStep` 按 `FightTable.Ability.type` 分发。原表标记 type 1 才是普攻、type 2 才是主动，这个类型与 ID 的首位数字或 `AbilityDes.type_des` 不等价。主线、引导与 PvP 共用相同类型投影。没有原主动就不发主动、不扣主动怒气；尚无原普通攻击的配置不伪造动作。具体执行效果与特殊机制仍单独验收。

## 技能等级换号

`HeroAbilityLogic.GetHeroSkills` 用 `quality*100+star` 取原等级行，正等级 `level` 将该槽 ID 替换成 `floor(id/10)*10+level`，零等级不选。1316、主线和 PvP 共用。不把 ID 末位升阶自行解释为额外伤害倍率。

## 突破技能

从 `heroTid*100+1` 到当前突破依次取 `UpStageTalent.skill` 和 `potential_skill`；固定职业技能、隐藏技能以及已开的星档槽各按其原来源加入。不可启用来源或门槛不匹配的目录候选，ID 已知而效果缺失时不猜。

## 专精技能

达到原专精条件且突破为正时加入 `mastery_ability+mastery_break-1`，无需先提升专精等级。只选当前档，有原 ID 没有同档效果时不回退首档。养成成本与 R2 属性累加不变。

## 稀有技能

持久化 `rare` 选择该角色的 `Rare.skill` 原被动引用，与普通主动并存。目录分类是显示信息，按原 type 3 执行已有同号触发；未明细则不补猜测。

## 异化技能

`661` 持久字段 `diff>0` 选本角色的 `Diff.skill`；组装、缓存与战报透传同一状态。未获原效果的异化引用不执行目录占位主动，也不当成 `Rare` 或 `HeroMutant`。

## 异变技能

用 `hero.mutant` 查原 `HeroMutant` 配置，只有 `belong_hero` 一致才加入 `extra_skill` 并标记战报 `is_mutant`。错属或未异变都不启用，不能从 `diff` 或 `rare` 推定。

## 天极技能

原 `HeroIsDefUR` 用角色基础品质 60/70，加入 `soul_ability` 而不替换已解锁的普通主动。战斗按原 `type=2/run_type=5` 单独选择，10 条有消耗证据的使用 3 点天极值，8 条证据不足不主动施放；始终禁止从怒气支付天极技。追加动作使用其实际技能 ID。原服选招优先级和未证效果仍非已恢复规则。

千千结 `2404040123` 保留原引用和原文案键 `601501120`，但本地原文案写汐夜且与其 `601501119` 重复；不注册破盾、月光，也不以另一形态 `2504030123` 的致盲条款填空。

## 注入精英对手

没有玩家养成状态的精英对手，不因与玩家共用 TID 就加载玩家效果或晚期被动。NPC 保留 `Npc_Ability` 的动作和兼容效果；不改原阵容未获证时对 `eliteEnemies` 的前置要求，也不将兼容效果写成原版 NPC 技能。

## 三消动作回放

三消的角色动作配置独立：玩家按当前星级 `BattleTriMatchHeroTable.UpStar.ability`，敌人按 `TripleMatchFightTable.NpcAbility.ability`，以三消 `Ability.type` 的 1/2 分别选择普攻、怒气技，棋盘技能 1/2/3 不作角色动作。此处仅核原引用，不恢复三消伤害、被动、技能等级或棋盘解算。

原棋盘验证链缺失期间，`115001–115004` 明确拒绝，不创建假局、不扣票、不登记无法结算的交换、不借普通自动战斗或推进塔。`115006` 原样读取保留期内的旧行动字节，不依当前星级重算；养成和阵容不受此限制。
