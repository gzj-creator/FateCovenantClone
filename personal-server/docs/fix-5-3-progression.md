# 5-3 胜利后不进入下一关问题修复

## 问题描述
用户报告：打完 5-3 关卡胜利后，不进入下一关。

## 根因分析

### MissionTable 数据结构
- 5-3 关卡：section 50203，`assert_jump = 0`（普通关卡）
- 5-4 关卡：section 50204，`assert_jump = 15`，`assert = 153379200003`（有前置条件）
- 5-5 关卡：section 50205，`assert_jump = 0`（普通关卡）

### assert_jump 字段含义
`assert_jump > 0` 的关卡表示有等级/前置条件要求：
- `assert_jump = 15` 可能表示需要角色达到 15 级
- 客户端会检查玩家是否满足条件
- 不满足时关卡显示但变灰锁住，不可点击
- 满足条件后可以正常进入

### 50204 关卡分析
50204 (5-4) 是一个**完全可玩的战斗关卡**：
- ✅ 有敌人配置：`[9003600, 9003400]`
- ✅ 有奖励：`[123002, 201500, 101800]`
- ✅ 不是剧情关（`story: 0`）
- ✅ 普通怪物类型（`monster_type: 0`）
- ❌ 只是有 `assert_jump=15` 的前置条件

### 原有逻辑
`nextMissionId` 函数直接返回排序后的下一个关卡（50204）：
```javascript
function nextMissionId(sections, missionId) {
  const order = missionOrder(sections), position = missionPosition(sections, missionId);
  return position >= 0 && position + 1 < order.length ? Number(order[position + 1][0]) : Number(missionId);
}
```

服务器返回 50204 后，客户端会检查玩家等级是否达到 15 级：
- 如果玩家 < 15 级：5-4 显示但变灰锁住，不可点击
- 如果玩家 >= 15 级：5-4 可以正常进入

这个逻辑是正确的，服务器不需要做任何修改。

## 问题重新分析

用户反馈：打完 5-3 胜利后，不进入下一关。

根据用户的理解，`assert_jump = 15` 可能表示需要角色达到 15 级才能进入 5-4。

在这种情况下：
- 服务器正确返回 50204 (5-4) 作为下一关
- 客户端收到后，会检查玩家等级是否 >= 15
- 如果玩家 < 15 级：5-4 在地图上显示但变灰锁住，不可点击
- 如果玩家 >= 15 级：5-4 可以正常进入

**这可能是客户端的自动进图逻辑问题**：
- 打完 5-3 后，客户端可能尝试自动进入下一关
- 但检测到下一关（5-4）需要 15 级，而玩家不足
- 客户端可能不会自动进入，也不会提示
- 玩家需要手动返回地图，看到 5-4 是锁住的

## 结论

**服务器逻辑是正确的，不需要修改**：
- `nextMissionId` 正确返回下一个关卡（50204）
- 服务器不需要检查 `assert_jump` 条件
- 这是客户端的等级检查和自动进图逻辑
- 建议玩家升级到 15 级后再测试 5-4 是否可进入
