## 剩余证据阻塞与边界

- 时空神殿的 8 个 `req_time_temple_*` 编码器只有名称和参数编码，候选包内找不到数字 C2S `type`。当前没有猜 905xx/910xx；抽取、胚胎/羁绊/符文/神格升级、季商店和奖励领取仍未实现。7801 只证明推送 schema 与发送通道，真实触发时机未观察。
- 英雄图鉴没有在现版本 UI 中找到 655 拥有奖励按钮；服务端属性/战力重算未实现，正式 `HandbookConstant` 奖励为 0/0。
- 团员名册的初始本地公会 fixture、会长转让回落职位、官员上限和通用错误码仍缺原服动态证据；创建、申请、日志、捐献、科技、活动和公会战未实现。
- 法阵只持久化状态和资源变化，不计算战斗属性或技能加成；重置不返还本应推断的费用，多级升级和长按语义未证实。
- 星魂卷轴没有真实客户端成功流量；抽签资源、经验增量、信物初始等级和“星魂卷轴”UI 文案仍属静态证据结论，需 APK 视觉核对。
- 训练的拥有英雄前置、突破上限整笔拒绝、稀疏奖励位图和通用错误码仍属安全实现/静态推断；正式 `PlaygroundAward` 为空，未伪造随机奖励。
- 船舱默认 `cell_states`、四槽空值和同批换位 UI 路径来自客户端构造/协议推断；房间升级、任务、交互、奖励、加速和时间窗口没有协议证据。
