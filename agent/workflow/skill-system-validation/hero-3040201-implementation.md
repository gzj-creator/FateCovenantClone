## 焚魂/腾焰机制说明

- 焚魂 (burn-soul): 每层降低目标防御/攻击/吸血效果，最多10层，持续2回合，死亡清除。每次普攻/绝招/终结技/天极技前为敌方全体添加1层不可驱散的焚魂。
- 腾焰 (soaring flame): 每触发3次灵犀协狩获得1层，每层提升5%最终暴击与20%暴击伤害，最多10层，持续至战斗结束。
- 反噬 (recoil): 终极技释放结束后激活，持续至当前回合结束。受到伤害时40%概率释放火刑 (100%法术+100%真实伤害+1层焚魂)。触发2次火刑后获得1层腾焰。
- 天极值 (Tianji): 终极技消耗3点。

这些机制 (层数叠加、天极值、反噬概率、火刑触发计数) 需要战斗引擎集成，当前仅做保守近似实现，requiresInvestigation=true。
