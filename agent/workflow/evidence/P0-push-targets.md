# P0 定向推送证据（2026-11-13）

## 结论

- `createRealtimePublisher` 只接受 `role`、`guild`、`server` 三类目标，不存在隐式广播分支。
- 服务调用未显式提供目标时，只解析当前认证角色；无角色上下文、目标格式错误或公会成员无法解析时丢弃并记录 `realtime_push_skipped`。
- 角色目标保留同一角色的全部在线连接；公会目标通过登录模块 24 的 `pb_res_guild_login.guildId` 解析在线成员；全服目标遍历全部连接。

## 调用点分类

| 来源 | 目标 |
| --- | --- |
| 活动阶段变化 `3301/3304` | 全服 |
| `role.levelUp` 产生 `7201` | 事件 roleId |
| 邮件 `900` | 收件 roleId |
| 世界聊天 `1400` | 全服 |
| 私聊 `1400` | 发送者与接收者两个 role 目标 |
| 公会成员变化 `2305` | 公会；退会时另发原角色以完成本地退出同步 |
| 任务统计、榜单成就、抽取统计、英雄实时结果 | 当前认证角色 |
| 钱包 `1900/9132`、时光神殿抽取 | 当前认证角色；钱包在推送前已 `runWithRole` 到订单角色 |

## 验证

- `test/realtime-publisher.test.mjs`：角色多连接、全服、公会、缺失上下文、非法目标、当前角色唯一隐式目标。
- `test/account-isolation.test.mjs`：三个真实 TCP 会话同时在线；角色邮件仅到目标角色，世界聊天到全部角色。
- `test/member-roster.test.mjs`：真实 TCP 公会成员变更通过公会目标送达。
- `test/chat-service.test.mjs`：世界聊天声明全服目标，私聊声明发送者/接收者两个角色目标。

本轮只使用临时 SQLite 和临时 TCP；未启停线上服务、未读写线上数据库、未操作模拟器/ADB/APK。
