- `ActFrameAct.type=182/187/189` 都绑定 `ActShopMgr/ActShopData`；不能只按 `big_type=6` 识别，服务还校验这两个

## 104801 行为

- 请求 schema 是 `pb_act_shop_info_req`，版本必须是正整数。
- 版本没有运行中的完整配置时返回空 `shop_list` 和 `is_act_open=false`；不会制造商品。
- 配置缺失、模块 92 缺失、ETF/protobuf 损坏或活动状态引用跨版本 goods/level 时返回 code 5。
- 如果登录阶段尚未创建状态，读取会在同一事务中创建空状态并写回模块 92；已有状态保留。
- 回包为 `pb_act_shop_info_rsp{shop_list,is_act_open}`。
