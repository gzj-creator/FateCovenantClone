# F1 每日必买与全局限购售罄

- 状态：主验收通过（组件 + 临时 SQLite/TCP 集成），已合入 main；未部署，未做 APK/视觉验收
- 子 agent：F1 / `f1_daily_sellout`

## 用户现象

每日必买一键购买后，两个付费礼包显示售罄，免费礼包仍显示可购买。有限购礼包的售罄状态应由同一服务端购买事实驱动。

## 调查证据

- 配置：`40006/tid=1` 为免费礼包 `101500 x30`；`40009/tid=2`、`46002/tid=5` 为两个付费单礼包；`46003/tid=6` 为 900 分的一键礼包，其 `batch_update` 仅配置 `[2,5]`。
- 运行库模块 108 当前为 tid `6`、`2`、`5` 的 `buy_times=1`，tid `1` 没有 `buy_times`，与“免费礼包仍可购买”一致。
- `analysis/tmp/DailyDiscountMgr.json` 的客户端方法映射已核对：`IsSelloutToday` 读取 `daily_discount_list` 对应行并比较 `buy_times/day_buy_times`；`CanBuyDailyDiscount` 同时考虑追加购买次数；`IsCanBuy` 最终调用该口径。`DailyDiscountGiftCardShowNode` 在不可购买时显示 `LocalizeTable.SELL_OUT`。
- `46003` 自身奖励为 `122702 x6`、`3002 x10`、`101500 x120`；免费礼包另有 `101500 x30`。一键礼包应把免费礼包作为同一个原子购买事实写入，并只发一次 30 星钻。
- 当前 `wallet-service.mjs` 的 `affectedDailyDiscountTids(46003)` 严格展开配置 `[6,2,5]`；重启回填使用同一函数，因此也不会恢复 tid 1。
- 当前 `purchaseGift()`（type 16005，免费礼包入口）只创建订单、发奖并写购买记录 flag 73，不写模块 108、不返回 flag 40，订单 payload 也没有 `daily_discount_purchase`，所以免费礼包独立购买后的即时/重启售罄口径同样未闭环。

## 根因

一键购买只消费配置表列出的 `[6,2,5]`，没有把免费礼包映射到 tid 1；同时 type 16005 的免费礼包购买没有通过同一个模块 108 计划提交购买事实。界面读取的是模块 108，而不是订单表，因此显示状态与购买流水不一致。

## 已落盘实现

- 新增 `personal-server/game/daily-discount-purchase.mjs`，集中解析：
  - 普通礼包只影响自身 tid；
  - 一键礼包消费自身、`batch_update` 依赖项；免费礼包 tid 1 尚未购买时一并消费；
  - 一键礼包付款时，免费礼包奖励有且仅有一次；免费礼包先买或追加购买时都不重复发放；
  - 缺失免费礼包或依赖配置时整包计划无效。
- 新增 `personal-server/test/daily-discount-purchase.test.mjs`，覆盖一键礼包 `[6,2,5,1]`、免费礼包按自身 tid 限购、缺失免费配置无效。
- 未修改共享 `wallet-service.mjs`、`gateway.mjs`、生产 SQLite、实时服务或客户端。

## 共享 wallet-service 建议 patch

以下改动需由主 agent 在 F3 钱包改动之后统一合并。行号基于当前 HEAD `8ab1f5c`。

1. 文件顶部 import 后增加：


2. 删除当前常量 `DAILY_DISCOUNT_VALUE_INDEX`（第 14 行）；映射已移入新 service。

3. 在 `dailyRechargeRowByProductId` 初始化之后插入，并替换当前 `affectedDailyDiscountTids` 函数（约第 90-105 行）：

```js
const dailyPurchaseRules = createDailyDiscountPurchaseRules({
  rows: dailyRechargeRows,
  rechargeTable: tables.Recharge
});
const dailyPurchaseFacts = product => {
  const facts = dailyPurchaseRules.resolve(product);
  if (!facts) throw new GameError(5, 'Daily discount product is not mapped');
  return facts;

const affectedDailyDiscountTids = product => dailyPurchaseFacts(product).affectedTids;
```

4. 替换整个 `planDailyDiscountPurchase()`（约第 115-144 行）。免费 tid 是 `optionalTids`：已购买时不能阻断付费礼包，未购买时在同一计划内消费；只有本次实际消费才发免费奖励：

```js
const planDailyDiscountPurchase = (modules, product, seconds, allowAdditional = false) => {
  const facts = dailyPurchaseFacts(product);
  const info = dailyDiscountInfo(modules);
  normalizeDailyDiscount(info, seconds);
  const optionalTids = new Set(facts.optionalTids);
  const rows = facts.affectedTids.map(tid => ({
    tid,
    row: dailyDiscountRow(info, tid),
    product: tables.Recharge.get(Number(dailyRechargeRowByTid.get(tid)?.recharge_id ?? product.tid))
  }));
  const requiredRows = rows.filter(({ tid }) => !optionalTids.has(tid));
  const regularAvailable = requiredRows.every(({ row, product }) =>
    product && Number(product.can_buy_times ?? 0) > row.buy_times
  );
  if (regularAvailable) {
    for (const { row } of requiredRows) row.buy_times += 1;
    let oneKeyFreeGiftConsumed = false;
    for (const { tid, row, product } of rows) {
      if (!optionalTids.has(tid) || !product
        || Number(product.can_buy_times ?? 0) <= row.buy_times) continue;
      row.buy_times += 1;
      oneKeyFreeGiftConsumed = true;
    }
    return { info, additional: false, oneKeyFreeGiftConsumed };
  }
  if (allowAdditional) {
    const additionalRows = rows.filter(({ row, product }) => {
      const rotation = dailyRechargeRowByTid.get(row.recharge_tid);
      return Boolean(rotation?.is_buy_additionally) && product?.can_buy_times > 0;
    });
    if (!additionalRows.length || additionalRows.some(({ row }) => row.buy_additionally <= 0)) return null;
    for (const { row } of additionalRows) row.buy_additionally -= 1;
    return { info, additional: true, oneKeyFreeGiftConsumed: false };
  }
  return null;
};
```
