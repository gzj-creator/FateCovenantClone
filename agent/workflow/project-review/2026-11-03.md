## P1：优先处理

### R01 更新请求的 URL 异常会终止整个服务

位置：[startup-service.mjs:12](/F:/projects/FateCovenantClone/personal-server/startup-service.mjs:12)。HTTP 回调直接调用 `new URL(request.url, ...)`，没有请求级异常处理。

在独立子进程的临时端口发送 `GET http://[ HTTP/1.1\r\nHost: 127.0.0.1\r\n\r\n`，Node HTTP parser 接受请求后，URL 解析抛出 `ERR_INVALID_URL`，进程退出码为 1。实际入口将更新、SDK、区服、网关和管理端放在同一进程，因此会一起中断。应在请求边界返回错误，避免异常逃逸。

### R02 合法数值请求在日志求值时抛错，退会和灵装合成无法执行

位置：[guild-roster-service.mjs:265](/F:/projects/FateCovenantClone/personal-server/game/guild-roster-service.mjs:265)、[fantasy-equipment-service.mjs:895](/F:/projects/FateCovenantClone/personal-server/game/fantasy-equipment-service.mjs:895)。`input?.toString('base64')` 对 ETF 解码后的 Number 调用了 `Number.toString`，将字符串当作 radix，抛出 `RangeError`。
